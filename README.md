# Birmingham Pulse - News Website

A modern, responsive news website for Birmingham with real-time updates from NewsAPI.

## Features
- Real-time news from NewsAPI (Your API key is pre-configured)
- Auto-updates every 15 minutes
- Responsive design for all devices
- Weather widget
- Trending news sidebar
- Newsletter subscription
- Search functionality
- Mobile-friendly navigation
- AdSense ready
- Offline support
